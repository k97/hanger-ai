# Naming round, 2026-11-28

This is the one file the batched naming round lives in (design §7). The orchestrator, the session coordinating the tracks, owns it: nobody else creates it or renames it. Each track's naming task appends that track's own section below: the new strings, a short researched brief for each first-time label (the app's nouns first, then what the engines, mcpick and macOS call the thing), and a `/humanizer` pass over every string. The track then stops for Karthik's sign-off, in Plannotator, on that section alone. Rounds run as tracks reach their naming task; they do not all happen before wave 1. Karthik's answers are recorded under the section they answer, and the plan's code takes them verbatim.
