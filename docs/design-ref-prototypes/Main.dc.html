The second line — what a server's registrations say about each other
One name can be declared in several config files. This line says whether those declarations match. It is suppressed entirely below two registrations, since one declaration has nothing to agree with.
A bug to fix whichever copy you pick: the Duplicate string hardcodes “declared twice”, but the count can be three or more. A server declared three times by one engine currently reads “3 registrations · declared twice by the same engine”.
