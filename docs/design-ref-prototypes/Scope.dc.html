Separate question: is “3 projects” true?

The count is linked project roots — the directories added to Hanger — not repositories on disk. Thirty repos under ~/Work with three linked reads “Reaches 3 projects”.

The existing “In 3 projects” note has the same scoping and nobody has minded, because “in” describes where Hanger found something. “Reaches” makes a claim about the engine's behaviour, and the engine reaches all thirty.

Either the copy narrows to what is counted, or the note accepts that it describes Hanger's view rather than the engine's. This is the string you approved on the 29th, believing it meant the latter.
