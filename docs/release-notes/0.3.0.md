The inspector now prices context. Select a skill or an MCP server and it tells
you what that asset costs a model on every request, in tokens, with every
figure computed in the backend rather than guessed in the interface.

## What a skill costs

A skill's Content tab carries a two-tier ledger. The first tier is what loads
on **every** request — SKILL.md in full, frontmatter included, measured rather
than estimated. The second is what the model only reaches for if SKILL.md tells
it to.

The Contents card is tied to what actually loads, so SKILL.md is marked as the
one entry read into context and the rest is shown as reachable, not resident.

## What an MCP server costs

A server's ledger leads with tokens and names the half it cannot measure.
Descriptions are measured; input schemas are not stored, so nothing in Hanger
can weigh them — the card says so rather than implying the total is complete.

Token figures are bytes divided by four. Treat them as a size, not a count.

The tools list beneath is now just what each tool is. The figures live in the
ledger above it instead of being repeated per row.

## Fixed

A server declared in several places with disagreeing launch commands showed a
single ledger for all of them. Each launch spec now gets its own.

A server whose probe failed showed a ledger of zero, which read as "this
carries nothing". It now says it was not measured.

Three statements in the context cards were not literally true of the code,
including a total that did not match the list below it. Corrected.

## Upgrading

No store migration; the schema stays at version 7.

Installs on 0.1.0 and 0.2.0 update in place from Check for Updates. A build
numbered 1.x, or 0.0.1, cannot update itself — take the DMG below once and
updating resumes normally.

## Install

macOS universal build, signed and notarised.
