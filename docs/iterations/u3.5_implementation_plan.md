# Implementation Plan — Iteration U3.5: Subagents (Inventory & Display ONLY)

This iteration adds support for scanning, inventorying, and displaying Custom Subagent definitions across global and project-level customize roots. Deploying or linking custom subagents is strictly out of scope.

---

## Scanner Detection Specification

Subagents are defined as Markdown files (with `.md` extension) containing YAML frontmatter.

### 1. Detection Paths
We will scan the following directories for each agent engine configuration:

#### A. Global Scopes
- **Claude Code**: `~/.claude/agents/*.md`
- **Codex**: `~/.codex/agents/*.md`
- **Gemini / Antigravity**:
  - `~/.gemini/agents/*.md`
  - `~/.gemini/config/agents/*.md` (and plugin directories `~/.gemini/config/plugins/*/agents/*.md` if matching directory exists)

#### B. Project-Level (Local Workspace) Scopes
- **Claude Code**: `[project_root]/.claude/agents/*.md`
- **Codex**: `[project_root]/.codex/agents/*.md`
- **Gemini / Antigravity**:
  - `[project_root]/.agents/*.md` (the flat convention)
  - `[project_root]/.agents/agents/*.md` (the nested convention to match global layout)


### 2. Frontmatter Parser
We will extract frontmatter content demarcated by `---`.
- **Fields to Parse**:
  - `name` (String, required)
  - `description` (String, required)
  - `tools` (List of Strings, optional)
- **Error Handling**:
  - If a file is missing YAML frontmatter, contains invalid YAML formatting, or lacks required fields, it will NOT cause a panic.
  - Instead, the scanner will record a warning in `parse_warnings` (e.g. `"Malformed frontmatter in subagent file at [path]: [error]"`) and continue.

## Domain Type Definition

We will add the `Subagent` struct to [domain.rs](file://~/Projects/demo/hanger-ai/src-tauri/src/domain.rs) aligned with the existing assets schema:

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Subagent {
    pub id: String,
    pub name: String,
    pub description: String,
    pub path: String,
    pub declared_tools: Vec<String>,
    pub scope: Option<Scope>,
    pub source_path: Option<String>,
}
```

We will also update `Inventory` in `domain.rs` to include `pub subagents: Vec<Subagent>`.

## Backend Deduplication & Flow

Inside `run_scan` and background scan tasks in [lib.rs](file://~/Projects/demo/hanger-ai/src-tauri/src/lib.rs):
- Scanned subagents will be merged into the unified inventory.
- Deduplication logic applies: Subagents with identical absolute `path` fields will be deduplicated.
