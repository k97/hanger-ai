Top navigation — a segmented track

Structurally, the loose chips become one continuous track and the selected category is a capsule that slides inside it: position in the track says "selected", so the check mark goes. The labels and the backend counts stay, and so does hide-at-zero with All, the selected category and MCP servers exempt (CategoryFilterCards.tsx). The slide is the app's one spring over --dur-nav. visionOS's glass is out — no blur, no shadow; the one elevation belongs to the map. Click a segment, or focus one and use the arrow keys then Enter.

Dark: --page (pure black) on --plane (one value step up) is a small step; the --line-2 edge carries the capsule. Flip Dark to judge.

Semantics

CategoryFilterCards renders buttons with aria-pressed (filters). Drawn as a tab view, role="tablist" / role="tab" + aria-selected fits: the list below changes with the category. Arrow keys move between tabs; the indicator follows focus only on selection.
