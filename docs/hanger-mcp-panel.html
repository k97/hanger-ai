A config file declares how to start a server, never what it provides. Verify starts a private copy, asks for its tool list, and stops it — no other host's session is touched.

What the study settles. Tool names are identifiers, so they are set in the mono face — semantic, not decorative. Descriptions are real and long enough to force two-line rows, which makes 17–20 tools taller than a panel, so the list is height-capped with internal scroll per DESIGN.md. The registration table is where cross-host divergence becomes visible; that is the job the nested-row design was straining to do. Health and protocol drift are the only places saturated colour appears, matching the token comment reserving it for system state.
