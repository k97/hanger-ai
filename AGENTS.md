Instructions for coding agents live elsewhere in this repo. Read, in order:

- `CLAUDE.md` — orientation, commands, the pinned verification gates.
- `.claude/rules/` — `coding-guardrails.md`, `verification.md` (what counts as
  evidence), `invariants.md`, `shared-checkout.md`, `ui-copy.md`,
  `verifying-ui.md`, `known-debt.md`, `releasing.md`.
- `.claude/DESIGN.md` — the design system, derived from code.

Before reporting any work as done, run the four gates in `CLAUDE.md` →
Verification, from the repo root. A figure from any other invocation is not a
gate result.
